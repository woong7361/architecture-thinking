### [12:03] refund_design.md 기반 bundled 테스트 초안 생성
- 맥락: 사용자가 `task1/refund_design.md`를 재료로 generate-test 스킬의 bundled 모드 테스트 초안 생성을 요청했다.
- 고민한 것: intake 질문을 먼저 할지, 설계 문서의 정책을 충분한 입력으로 보고 바로 파이프라인을 실행할지 판단했다. 문서에 정책 우선순위, 경계값, 예외, 미결 사항 없음이 명시되어 있어 추가 질문 없이 진행했다.
- 트레이드오프: 추가 질문을 하면 정책 공백을 더 엄밀히 확인할 수 있지만, 이미 `미결 사항: 현재 없음`이고 bundled 요청이 명확해 실행이 지연된다. 바로 실행하면 빠르게 산출물을 얻지만, 숨은 도메인 의도는 반영하지 못할 수 있다.
- 결론: 설계 문서 원문 전체를 `source_material`로 넣고, 정책 규칙만 `policy_rule`로 분해해 입력 JSON을 생성한 뒤 bundled 모드로 실행했다.
- 어떻게 했는가: `AGENTS.md`, generate-test `SKILL.md`, 파이프라인 `AGENTS.md`, 관련 schema/prompt/rubric을 확인했다. `intake_to_input.py`로 `.codex/skills/generate-test/pipeline/inputs/d822a08f_input.json`을 생성했고, `run_draft.py --mode bundled`로 `runs/bundled/2026-07-06_d822a08f`를 생성했다. `.codex` 하위 쓰기가 샌드박스 읽기 전용 제한에 걸려 승인 후 실행했다.
