# Task B-7: AI에게 시키고, 객체지향으로 판단하기 (비교 실험)

(Grit's Why): 객체지향이 AI 시대에 왜 기본기인지는 설명으로는 잘 안 와닿습니다. 직접 겪어야 합니다. 이 Task는 그 체감을 만드는 자리입니다.

### 수행 내용

1. 같은 요구사항(예: B-2의 티켓 예매)을 두 방식으로 AI에게 구현시키세요. (a) 아무 제약 없이 '구현해줘'로 받은 버전, (b) 본인이 B-3/B-4에서 세운 책임 분리와 의존 방향을 명시해 지시한 버전.
2. 두 버전 모두에 같은 변경 요구를 가하세요 (예: 포인트 결제 추가, 또는 외부 결제사 교체). 각 버전에서 무엇을 얼마나 고쳐야 했는지, 1-1의 인수테스트는 여전히 통과하는지 기록하세요.
3. 두 버전의 변경 비용 차이를 구조와 수치(고친 파일/메서드 수 등)로 비교하고, AI에게 무엇을 어떻게 지시했을 때 더 제어 가능한 코드가 나왔는지 본인 결론을 적으세요.

### 제출물

- [ ]  두 버전의 코드(또는 링크)와 같은 변경을 가한 결과.
- [ ]  변경 비용 비교(구조 + 수치) + 본인 결론. (최소 400자)
