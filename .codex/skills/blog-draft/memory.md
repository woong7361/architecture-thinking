# memory.md — 누적 교훈

blog-draft 초안에 대한 사용자 피드백에서 얻은 **교훈**을 쌓는 곳이다.

- 부정 피드백 → 회피 교훈("~하지 마라"), 긍정 피드백 → 성공 패턴("~가 통했다").
- 원본 반응(raw)은 `problem.md`의 "사용자 피드백 누적" 섹션에 남기고, 여기엔 일반화된 교훈 한 줄만 적는다.
- 같은 교훈이 반복되면 사람이 확인 후 `soul.md`(고정 취향)로 승격한다.

gen / refine 단계에만 주입된다. critique / eval에는 주입하지 않는다.

## 형식

```
- [neg|pos] (YYYY-MM-DD, run_id) 교훈 한 줄
```
