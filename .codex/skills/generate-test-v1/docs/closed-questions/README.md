# 닫힌 질문 (closed-questions)

[open-questions/](../open-questions/)와 짝을 이루는 폴더. **결론이 난 열린 질문을 여기로 옮긴다.**

## 규칙

- 토론이 결론(선택 + 근거)에 도달하면 `open-questions/`의 문서를 이 폴더로 **이동**한다(복사 아님).
- 옮길 때 문서 상단 상태를 `열림(토론 중)` → `닫힘(YYYY-MM-DD, 결론=<한 줄>)`로 바꾼다.
- 문서 끝의 "후보 방향" 중 **무엇을 왜 골랐는지**를 "결론" 절로 추가한다.
  ([../phase4-split-vs-bundled.md](../phase4-split-vs-bundled.md)의 "선택: split" 형식을 따른다.)
- 자매 문서 간 링크(`open-questions/` ↔ `closed-questions/`)는 이동 후 경로를 갱신한다.
