# CHANGELOG — generate-test 파이프라인 변경 이력

slow loop(자가개선 제안)을 사람이 검토·수락해 파이프라인 파일(gen 프롬프트·rubric·intake 등)을 바꿀 때마다
여기에 한 줄을 남긴다. 형식은 아래. 과거 버전 스냅샷은 git이 관리하므로 만들지 않는다(commit 해시로 되돌아간다).

형식:

```
## <component>:vN (YYYY-MM-DD)
- 변경: 무엇을
- 겨냥 axis: 어느 축/신호를 올리려는가
- 근거: 근거 run hash / 신호
- 위험: 낮음 | 중 | 높음
- commit: <적용 커밋 해시>
```

> proposer는 이 파일을 자동 수정하지 않는다. `proposal-final.md`의 "CHANGELOG 초안"을 사람이 검토해 여기 옮긴다.
> slow loop 자신의 판정 장치(`rubric_proposal.yaml`, `propose_*.md`, slow-loop 코드)는 제안 대상이 아니며 사람만 바꾼다(고정점, §5).
