아니다. 다시 찾아보니 이전의 `faster-whisper + 단어 타임스탬프 + VAD` 안은 **안정적인 범용안**이지, taskD-5의 최소 요구에 가장 간단한 안은 아니다.

현재 가장 작은 MVP 후보는 **`SeloWhisper-ko-disfluency` 단일 전사 패스 + 간단한 계산기 + 구조 비평 프롬프트**다.

```text
음성·영상
  -> SeloWhisper 전사
     <um> <uh> <gue> <repeat> 같은 태그 포함
  -> 태그 개수 / 녹화 길이로 빈도·속도 계산
  -> 전사문을 D-4 계획과 비교해 구조 피드백
```

## 왜 더 간단한가

[SeloWhisper-ko-disfluency](https://huggingface.co/rearleg/SeloWhisper-ko-disfluency)는 `음`, `어`, `그`를 일반 텍스트로 받아 적은 뒤 문맥으로 다시 분류하는 대신, 전사 단계에서 `<um>`, `<uh>`, `<gue>` 같은 전용 토큰으로 출력한다. `아/어/음/그/저/뭐/막`, 반복, 웃음, 기타 비유창성까지 10개 타입이 정의되어 있고 MIT 라이선스다.

따라서 MVP에서 필요한 코드는 다음 세 가지면 된다.

1. 영상에서 16kHz mono 음성을 추출하고 Transformers ASR pipeline으로 전사한다.
2. 특수 토큰을 세고 `횟수 / 녹화 분`으로 필러 빈도를 계산한다. 말 속도는 `한국어 글자 수 / 녹화 분`으로 계산한다.
3. 전사문과 D-4의 도입·핵심·예시·마무리 계획을 LLM에 주고 근거 문장과 함께 차이를 출력한다.

긴 녹음은 Transformers의 `chunk_length_s`와 `stride_length_s`로 나눌 수 있다. taskD-5가 요구하지 않은 단어별 정밀 타임스탬프와 침묵 분석은 첫 버전에서 제외한다. [Transformers ASR pipeline 공식 문서](https://huggingface.co/docs/transformers/main_classes/pipelines)

## 그래도 누락 검증은 없어지지 않는다

모델 카드의 자체 평가에서도 filler recall은 clean 0.8488, noisy 0.9039다. 이 수치대로라면 해당 평가 데이터에서도 실제 필러의 약 9.6~15.1%가 빠졌다. 게다가 이 평가는 필러 종류별 전체 개수만 비교하므로 발생 위치가 맞는지는 검증하지 않는다. 방법론과 학습 데이터도 아직 공개하지 않고 향후 논문으로 미뤘다.

그러므로 “누락 검증 불필요”라고 말할 근거는 없다. 다만 검증 방법은 단순화할 수 있다.

- D-4 첫 녹화 3~5분에서 사람이 필러만 한 번 표시한다.
- SeloWhisper 결과와 대조해 종류별 `맞음/누락/오탐`을 기록한다.
- 해당 녹음을 같은 화자·마이크 조건의 고정 캘리브레이션 샘플로 남긴다.
- 결과가 충분하면 이후에는 전수 청취 대신 자동 결과의 의심 구간만 확인한다.

이것은 매번 검증하는 절차가 아니라 **모델이 나의 한국어 말버릇을 얼마나 잡는지 한 번 재는 절차**다.

## 선택지 비교

| 선택지 | 단순성 | 필러 적합성 | 남는 문제 |
|---|---|---|---|
| **SeloWhisper 단일 패스** | 가장 작음 | 한국어 필러 전용 토큰 | 0.8B 모델, 자체 평가뿐, 정밀 타임스탬프 미검증 |
| faster-whisper 단일 패스 | 설치·장문·타임스탬프가 안정적 | 일반 Whisper라 필러 누락 가능 | 문자열 분류와 검증 필요 |
| SeloWhisper + faster-whisper 2패스 | 구성 요소가 늘어남 | 필러 태그와 정밀 시각을 각각 얻음 | 현재 과제에는 과도함 |

완성형 오픈소스 발표 코치도 찾았지만 더 단순하지 않았다. [VoxLab](https://github.com/yaotingchun/VoxLab)은 WPM·필러·구조를 모두 제공하는 대신 Google Cloud Speech-to-Text, Gemini, Firebase가 필요하다. `pitchprompter-ai`는 로컬 Whisper 연동이 아직 계획 단계다.

## 수정된 추천

개인 과제용 MVP라면 **SeloWhisper 단일 패스부터 시작한다.** 첫 D-4 녹화에서만 필러를 수동 라벨링해 모델을 검증한다. 검증 결과가 나쁘거나 단어별 타임코드·침묵 분석이 실제로 필요해질 때만 `faster-whisper`를 두 번째 패스로 추가한다.

즉, 이전 추천은 범용성과 확장성 기준이었고 이번 추천은 taskD-5의 최소 요구 기준이다. 지금은 후자가 더 맞다.
