# 변경 범위와 근거

- 대상은 `task2/assignments/taskB-0.md`부터 `taskB-7.md`까지 8개 파일이다. 현재 각 파일에 `<!-- notion-feedback:begin -->`과 메타데이터 HTML 블록 주석이 같은 구조로 있다.
- 프로젝 전체 검색에서 `notion-feedback:begin`을 참조하는 스크립트나 문서는 발견하지 못했다. 바로 아래의 `## 리뷰 피드백` 제목이 섹션 경계를 대신할 수 있어 해당 표식은 제거한다.
- 피드백 본문과 출처, URL, 수집 방법, 원문 보존, 라인 기준 정보는 모두 보존한다. 변경은 피드백 메타데이터 구간에만 한정한다.

# 표현 방식 비교

1. Markdown 인용 목록으로 표시하는 방식을 선택한다. HTML을 완전히 없애면서 기존 정보를 같은 문서에 보존할 수 있다. 단점은 기존에 숨겨져 있던 메타데이터가 렌더링 결과에 보인다는 점이다.
2. 메타데이터를 별도 파일로 옮기면 본문을 간결하게 유지할 수 있지만, 8개 문서와 출처 정보의 연결을 추가로 관리해야 한다. 사용자가 현재 파일의 주석을 Markdown로 바꾸라고 했으므로 선택하지 않는다.
3. `[//]: # (...)`같은 숨김 주석 관례는 표준 Markdown 주석이 아니고 복수 줄 메타데이터를 안정적으로 표현하기 어렵다. 렌더러 호환성에 의존하므로 선택하지 않는다.

# 구체적인 변경

- `<!-- notion-feedback:begin -->`은 제거한다.
- HTML 블록 주석을 `> **피드백 메타데이터**`와 `> -` 목록으로 바꾼다.
- URL은 `<https://...>`로 표시해 순수 Markdown 내에서 클릭 가능하게 한다.

# 검증 기준

- 8개 파일에서 `<!--` 및 `-->` 패턴이 0건인지 확인한다.
- 변경 후에도 출처 정보 5개 필드가 각 파일에 남아 있는지 확인한다.
- `git diff -- task2/assignments`로 피드백 메타데이터 구간 외의 본문이 변경되지 않았는지 확인한다.
