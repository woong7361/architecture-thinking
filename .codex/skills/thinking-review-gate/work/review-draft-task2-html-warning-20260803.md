원인은 `task2/assignments` 문서에 들어간 **HTML 주석**입니다. Markdown 확장자여도 편집기가 `<!-- ... -->`를 보고 HTML이 섞인 문서로 판정해, 일반 문서 편집 모드 대신 코드 모드만 허용하는 것으로 보입니다.

예를 들어 `taskB-0.md`에는 다음 내용이 있습니다.

```md
<!-- notion-feedback:begin -->

<!--
  출처 페이지 : ...
-->
```

같은 패턴이 `taskB-0.md`부터 `taskB-7.md`까지 모두 있습니다. `task1/assignments`에서는 검색되지 않아 `task2`에서만 보이는 현상과도 맞습니다.

이는 파일이 잘못되었다는 뜻은 아닙니다. 코드 모드에서는 그대로 편집해도 됩니다. 일반 Markdown 편집 모드를 쓰고 싶다면 HTML 주석을 제거하거나, 같은 메타데이터를 별도 파일로 옮기면 됩니다. 다만 정확한 편집기 내부 판별 규칙은 공식 문서에서 확인하지 못했으므로, `<!-- ... -->`가 직접 트리거라는 결론은 프로젝트 파일 비교에 기반한 강한 추정입니다.
