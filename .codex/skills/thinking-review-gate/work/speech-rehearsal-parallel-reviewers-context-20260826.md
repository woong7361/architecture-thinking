# Context

- 과제 D-5는 D-4 녹화의 transcript를 입력받아 필러 워드 빈도, 말 속도, 도입-핵심-마무리 구조를 피드백하는 에이전트와 실제 피드백 결과를 요구한다.
- 사용자는 로컬 모델 실행과 음성 파일의 수동 분할을 원하지 않는다.
- 현재 후보 전사 경로는 Codex가 OpenAI Audio transcription API의 `gpt-transcribe`를 호출하는 방식이다. Codex 코딩 모델 자체가 음성을 직접 청취한다고 가정하지 않는다.
- OpenAI 공식 문서상 Codex는 `.codex/agents/*.toml`의 project custom agent를 사용할 수 있고 독립 작업을 병렬로 실행한 뒤 상위 에이전트가 종합할 수 있다.
- 프로젝트는 skill과 공용 프롬프트·rubric에서 특정 발표 주제에 고정된 규칙을 피하고, 도메인 중립 규칙과 실행별 입력을 분리하도록 요구한다.
- 사용자가 제안한 변경은 Python이 필러를 문자열 규칙으로 판별하지 않고 AI reviewer가 문맥으로 분류하게 하는 것이다.
- transcript만으로는 단어 선택, 문장 종결, 반복, 머뭇거림 같은 언어적 어투는 평가할 수 있지만 음높이, 음량, 에너지, 강세 같은 실제 음성 운율은 완전히 평가할 수 없다. 단어 또는 구간 timestamp가 있으면 말 속도와 멈춤은 계산할 수 있다.
- 설계 승인 전이므로 실제 skill과 agent 파일은 아직 구현하지 않는다.
