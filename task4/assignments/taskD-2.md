# Task D-2: 기술 에세이 (데이터 기반 4-Step)

(Grit's Why): 좋은 기술 글은 교과서 요약이 아니라 '문제를 어떻게 풀었나'의 서사입니다. 면접관은 '추정 → 소거 → 확신 → 검증'이 글에 드러날수록 그 사람의 논리력을 봅니다.

### 수행 내용

1. 1-1~1-3에서 본인이 실제로 한 작업 하나(예: 헥사고날로 어댑터 교체를 무수정으로 만든 일, 또는 인수테스트로 AI 코드를 판정한 일)를 골라, 4-Step으로 기술 에세이를 쓰세요. (1) 문제 정의 (2) 증거/관찰 (3) 대안 분석과 의사결정(왜 이 선택인가, 트레이드오프) (4) 검증.
2. 가능하면 Before/After를 정량(또는 구조 변화)으로 보여 주세요. 교과서식 개념 나열은 금지.
3. 초안을 완성하세요. D-5 하네스를 통과시킨 퇴고본을 발행하고 링크를 제출합니다.

### 제출물

- [ ] 발행된 기술 에세이 링크 + 4-Step이 드러나는지 자가 점검 메모. (최소 300자)
