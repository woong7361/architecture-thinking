# Task D-3: 성장 에세이 (설계의 언어화)

(Grit's Why): 기술 에세이가 '무엇을 했나'라면, 성장 에세이는 '그 3주에 내 사고가 어떻게 바뀌었나'입니다. 발행되지 않은 사고는 존재하지 않습니다.

### 수행 내용

1. 1-1~1-3을 지나며 '왜'를 3겹 이상 파고든 지점 하나를 골라, 사고 전환을 성장 에세이로 쓰세요. (예: '테스트는 귀찮은 것' → '테스트는 AI 코드를 판정하는 게이트'로 바뀐 과정.)
2. 회고에 본인만의 성장 정의를 담으세요. 무엇을 어디까지 했고, 다음에 무엇을 더 할지.
3. 초안을 완성하세요. D-5 하네스를 통과시킨 퇴고본을 발행하고 링크를 제출합니다.

### 제출물

- [ ] 발행된 성장 에세이 링크 + 사고가 바뀐 지점을 짚은 메모. (최소 300자)
