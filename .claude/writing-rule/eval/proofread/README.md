# 교정 하네스 문구 측정

`.claude/skills/proofread/checks/`의 판정 문구를 고칠 때 쓰는 자료다. 단계마다 따로 잰다.

## 자료

단계마다 디렉터리 하나를 둔다.

- `items.md` — 문단이나 절 단위의 항목 목록. 일부에 결함을 심고 나머지는 정상으로 둔다. 주제는 서로 다른 분야에서 고른다.
- `labels.md` — 위 항목의 정답. 판정하는 쪽에 주지 않는다.
- `round<n>.md` — 회차별 결과와 항목별 판정.

## 자료를 모으는 곳

실제 글에 하네스를 돌린 회차에서 모은다. 사용자가 기각한 판정은 헛지적 사례로 `items.md`에 넣고 정답을 정상으로 적는다. 사용자가 집었는데 하네스가 놓친 자리는 결함 사례로 넣는다. 지어낸 문장보다 실제로 갈린 자리를 먼저 쓴다.

## 절차

1. 문구 하나를 파일로 적는다.
2. 맥락을 모르는 에이전트에 `checks/common.md`와 그 단계 파일과 `items.md`만 준다. 정답은 주지 않는다.
3. 잡은 수와 놓친 항목과 헛지적한 항목을 센다. 헛지적은 놓침과 같은 무게로 센다.
4. 같은 문구로 글을 한 편 고치게 해서 수정 쪽 부작용을 본다. 판정만 맞고 고칠 때 과하게 지우는 문구가 있다.
5. 실제 글에 걸어 보고 손 판정과 대조한다.
