# 판정 대상 2: 묶음을 여는 자리

각 항목은 어떤 글에서 소제목과 그 아래 머리 문단, 그리고 바로 뒤에 오는 첫 하위 소제목까지를 잘라 온 것이다.

## S1

```
## 월세 계약에서 보증금을 잃는 길은 네 가지다

집주인에게 돈을 맡기는 순간, 그 돈이 언제 돌아오는지는 세입자가 정할 수 없다.

### 첫째. 집이 경매로 넘어가면 받을 순서가 밀린다
```

## S2

```
## 반죽이 부풀지 않는 까닭은 세 가지다

부풀기는 효모가 내는 가스를 반죽이 붙잡아 두는 일이다. 그래서 효모가 죽거나, 가스가 덜 나오거나, 반죽이 가스를 못 붙잡으면 부풀지 않는다.

### 첫째. 물이 뜨거우면 효모가 죽는다
```

## S3

```
## 자전거 브레이크가 늦게 듣는 까닭은 세 가지다

늦게 듣는다는 것은 손잡이를 당긴 뒤 바퀴가 멈추기까지 시간이 걸린다는 말이다. 원인은 줄, 패드, 림에 각각 있고, 셋을 어떻게 손보는지는 아래 '정비' 절에서 다룬다.

### 첫째. 줄이 늘어나면 당기는 힘이 늦게 전해진다
```

## S4

```
## 번역을 기계에 맡기면 세 가지가 어긋난다

기계는 문장을 문장으로 바꾸고 글을 글로 바꾸지 않는다. 어긋나는 자리는 어휘의 짝, 문장의 순서, 글 전체의 어조 셋이다.

### 첫째. 어휘의 짝이 원문의 짝을 그대로 따라온다
```

## S5

```
## 모종이 자라지 않는 까닭은 세 가지다

흙과 물과 빛 가운데 하나가 모자라면 모종은 자라지 않는다. 특히 흙이 굳으면 뿌리가 숨을 못 쉬어서, 물을 더 줘도 뿌리가 썩기만 하고 잎은 그대로 노랗게 남는다.

### 첫째. 굳은 흙은 뿌리가 숨을 못 쉬게 한다
```
