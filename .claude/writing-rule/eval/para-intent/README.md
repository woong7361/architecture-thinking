# 문단 규칙 문구 측정

`CLAUDE.md`의 「문단」절 문구를 정할 때 쓴 자료다. 문구를 바꿀 때 같은 절차를 다시 돌린다.

## 자료

- `items.md` — 문단 열두 개. 여덟 개에 결함을 심고 네 개는 정상으로 두었다. 결함은 의도 둘, 끝에서 화제 이동, 중간에 끼어든 화제, 가리킬 앞 문장이 없는 접속어, 끊긴 사슬, 뒤 절 예고, 뒤 문단 내용 앞당김이다. 주제는 모두 다른 분야에서 골랐다.
- `labels.md` — 위 항목의 정답. 판정하는 쪽에 주지 않는다.
- `v0`~`v6` — 규칙 문구 변형. v0은 규칙 없음이고, v6이 채택본이다.
- `gen-task.md` — 생성 테스트 과제. 메모에는 뒤 절에 속하는 항목을 섞어 두어 앞당김이 일어나기 쉽게 했다.
- `out-v1.md`, `out-v4.md` — 같은 과제를 서로 다른 문구로 쓴 결과.
- `doc-labels.md` — 실제 문서에 대한 손 판정. 에이전트 결과를 보기 전에 적었다.
- `round1.md`, `round2.md` — 회차별 결과와 조항별 판정.

## 절차

1. 문구 하나를 파일로 적는다.
2. 맥락을 모르는 에이전트에 그 문구와 `items.md`만 주고, 항목마다 위반 여부와 걸린 문장 번호를 한 줄로 받는다. 정답은 주지 않는다.
3. 잡은 수, 놓친 항목, 헛지적한 항목을 센다. 헛지적은 놓침과 같은 무게로 센다. 문단을 과하게 쪼개는 문구가 거기서 걸린다.
4. 같은 문구로 글을 한 편 쓰게 해서 생성 쪽 부작용을 본다. 판정만 잘하고 쓰기에서 문단을 토막 내는 문구가 있다.
5. 실제 글에 걸어 보고, 손 판정과 대조한다.
