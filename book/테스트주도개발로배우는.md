# 테스트 주도 개발로 배우는 객체 지향 설계와 실전
스티븐 프리먼, 냇 프라이스

인수테스트를 작성하는 것으로 시작한다.
실패하는 인수 테스트 -> 실패하는 단위 테스트 -> 테스트 통과 -> 리팩터링 loop  
인수 테스트 - 전 구간을 테스트해라

잘못 설계하면 단위테스트를 작성하거나 이해하기가 힘들다(클래스가 멀리 떨어져있는 시스템의 일부와 긴밀하게 결합되어있거나 암시적인 의존성이 있거나, 불분명한 책임이 너무 많으면)

값과 객체 설계 - 값은 변하지 않는 양이나 크기, 객체는 시간이 지남에 따라 변할지도 모르는 식별자가 있는 계산절차
