# Task E-0: 이번 Station의 책 (마인드셋 1권 + 기술 + 팀그릿)

(Grit's Why): API와 설계는 도구가 아니라 무엇이 가치인가라는 판단입니다. 컨셉 수업으로 그 판단의 근거를 잡습니다.

### 읽기 범위 (3축)

- [마인드셋] 컨셉 수업: 기능과 의미의 차이, 컨셉이 가치의 설계도이자 판단 기준이라는 대목을 정독하세요. 아이디어(공급자가 하고 싶은 것)와 컨셉(고객이 설레는 것)의 구분이 핵심입니다.
- [기술] 팀그릿 ai-backend-guide Ch3(외부 연동 6원칙)과 Ch12(RESTful)를 API 계약 작성 직전에 펼치세요.
- [팀그릿] harness-engineering-playbook Ch4(validate + rubric): E-5의 API Contract 검증 에이전트에 직접 연결됩니다.

### 제출물

- [ ] [컨셉 수업] 충격 구절이나 개념 세 가지와 왜 본인 설계관이 흔들렸는지. (최소 400자)
- [ ] 기능 중심 제품이 의미 중심 제품을 이기지 못하는 이유를 책 속 사례 1개를 인용해 정리. (최소 300자)
