# Task G-0: 이번 Station의 책 (마인드셋 1권 + 기술 + 팀그릿)

(Grit's Why): 2-2에서 무질서가 숨은 취약성을 드러낸다는 것을 봤다면, 이번엔 그 무질서를 측정 가능한 신호로 바꿉니다. 막연한 불안을 숫자로 환산하는 것이 엔지니어의 일입니다.

### 읽기 범위 (3축)

- [마인드셋] 『안티프래질』(나심 탈레브, 2-2에서 잇기): 변동성과 스트레스를 제거하는 것이 아니라 측정하고 활용하는 관점을 G-4 벤치마크와 연결하세요.
- [기술] 『자바 동시성 프로그래밍』(브라이언 고에츠 외) + 팀그릿 ai-backend-guide Ch8: 락 전략별 처리량과 지연의 트레이드오프를 측정 관점에서 읽으세요.
- [팀그릿] vibe-engineering-guide Ch5 + harness-engineering-playbook 스코어카드: G-4의 벤치마크 자동화 에이전트와 스코어카드 비교에 직접 연결됩니다.

### 제출물

- [ ] [안티프래질] 변동성을 제거 대상이 아니라 정보로 보는 관점이 본인 성능/장애 사고를 어떻게 바꿨는지. (최소 400자)
- [ ] [기술서] 락 전략 하나가 다른 전략보다 유리한 조건과 불리한 조건을, 책 속 설명 1개를 인용해 정리. (최소 300자)
